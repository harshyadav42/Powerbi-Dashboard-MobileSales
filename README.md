## 📌 Project Overview

This project focuses on analyzing mobile sales data using **Microsoft Power BI** to create an interactive and visually appealing sales dashboard.

The dashboard provides valuable insights into sales performance, customer ratings, transaction trends, payment preferences, brand performance, and mobile model popularity.

## ✨ Dashboard Features

### 1. 📍 Sales Analysis by City
- Interactive geographical map displaying sales distribution across different cities.
- Helps identify major sales-performing locations.

### 2. 📅 Monthly Sales Quantity
- Line chart representing total quantity sold across all 12 months.
- Helps identify monthly sales trends and fluctuations.

### 3. ⭐ Customer Ratings Analysis
- Visual representation of customer ratings from 1 to 5.
- Helps understand customer satisfaction and feedback.

### 4. 💳 Payment Method Analysis
- Pie chart showing transaction distribution by:
  - UPI
  - Debit Card
  - Cash
  - Credit Card

### 5. 📱 Mobile Model Performance
- Compares total sales generated by different mobile models.
- Identifies top-performing mobile devices.

### 6. 🏷️ Brand Performance
- Tabular analysis of brands based on:
  - Total Sales
  - Total Quantity

### 7. 📊 Sales by Day Name
- Analyzes sales performance across different weekdays.
- Helps identify high-performing sales days.

## 🎛️ Interactive Filters & Slicers

The dashboard includes interactive slicers to make data exploration easier:

- 📱 Mobile Model
- 💳 Payment Method
- 🏷️ Brand
- 📅 Day Name
- 🗓️ Month Selection

Users can apply multiple filters to analyze specific segments of the sales data.

## 🛠️ Tools & Technologies Used

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPI analysis.
- **Data Visualization** – Interactive charts, maps, tables, and slicers.
